# Reel Cover Kit — @prihisol

Branded first-images (1080×1920) for existing reels that have none. The title sits in the vertical center, so Instagram's grid crop keeps it visible.

## How to apply (per reel, ~20 seconds)

1. Save the PNG to your phone (or AirDrop/transfer the folder).
2. Instagram → your reel → **⋯ → Edit → Edit cover → Add from device** → pick the matching cover → Save.

## Which cover for which reel

| File | Use for |
|---|---|
| `reel-cover_camino.png` | The Camino de Santiago reel (its own line: "La verdadera magia está en cada paso.") |
| `reel-cover_movimiento.png` | Any moving/travel/life-chapter reel |
| `reel-cover_cultura-familia.png` | Family, food, Costa Rica, home reels |
| `reel-cover_la-priscilla-real.png` | Funny/everyday/real-life reels |
| `reel-cover_latina-power.png` | Confidence/identity/celebration reels |

## Notes

- These are type-only cards (v1). Once photos land in `photos/`, photo-forward covers per reel can be rendered with the same template — same look, your image as the hero.
- Palette/fonts are the provisional whimsical-warm set (strategy brief §9) — when the look is signed off or tokens change, re-render the kit with the same script.
