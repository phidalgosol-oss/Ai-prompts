# Contributing

These prompts are living documents. If you use them and discover something better, share it.

## How to Contribute

**Found an issue with a prompt?**  
Open an issue describing:
- Which prompt had the problem
- What you asked Claude to do
- What went wrong
- How you fixed it (if you did)

**Have a better version?**  
Pull requests welcome. Please include:
- What changed and why
- Before/after examples if possible
- Any new sections or clarifications

**Have a new prompt?**  
We're interested in:
- Prompts that solve real design/build problems
- Techniques that saved you time or money
- Approaches that work across different use cases

Send a PR with:
- The prompt file (markdown)
- Real examples from your work
- 2-3 use cases when it applies
- Any limitations or edge cases

## Guidelines

- **Keep it real.** No theory without proof. Use examples from actual projects.
- **Keep it clear.** Write like you're explaining to a colleague, not a textbook.
- **Keep it short.** If a prompt is >500 words, break it into smaller pieces.
- **Attribute your work.** If you build on someone's prompt, credit them.

## Code of Conduct

- Be kind to people asking questions
- Assume good faith
- No gatekeeping on who "should" use AI
- Share your knowledge. That's the whole point.
